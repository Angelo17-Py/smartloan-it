SmartLoan IT

Sistema de Prestamo de Equipos Tecnologicos

SmartLoan IT es un sistema web para la gestion y control de prestamos de equipos tecnologicos (laptops, PCs, tablets, etc.) en instituciones educativas.

Los administradores tienen credenciales asignadas internamente por el departamento de sistemas.

Funcionalidades

  • Registro y control de prestamos de equipos
  • Gestion de alumnos, equipos y encargados
  • Devoluciones con calculo automatico de multas
  • Dashboard con metricas en tiempo real
  • Roles de acceso: administrador y solo lectura
  • Comprobantes descargables en Excel
